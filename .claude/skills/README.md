# Skill descriptions for review

Use this as a quick filter for deciding which symlinked skills to keep in this repo.

| Skill                         | Description                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| diagnose                      | Disciplined debugging loop for hard bugs/perf issues: reproduce, minimize, instrument, fix, regression-test. |
| grill-me                      | Interactive design grilling that asks one question at a time to stress-test a plan.                          |
| grill-with-docs               | Same grilling approach, but grounded in project docs/domain language and updates docs as decisions land.     |
| handoff                       | Produces a compact handoff document so another agent can continue work quickly.                              |
| improve-codebase-architecture | Finds architectural deepening/refactor opportunities to improve testability and navigability.                |
| prototype                     | Builds throwaway prototypes (state/logic or UI variants) to answer design questions before committing.       |
| setup-matt-pocock-skills      | Bootstraps repository config/context those skills expect (issue tracker, labels, doc layout).                |
| tdd                           | Runs a red-green-refactor workflow focused on behavior-first tests via public interfaces.                    |
| to-issues                     | Breaks a plan/PRD into independently grabbable vertical-slice issues.                                        |
| to-prd                        | Synthesizes current context into a PRD and publishes it to the project issue tracker.                        |
| triage                        | Moves issues through a defined triage state machine using triage roles/labels.                               |
| write-a-skill                 | Helps create new reusable agent skills with proper structure and resources.                                  |
| zoom-out                      | Requests a higher-level map of modules/callers to understand unfamiliar code areas.                          |
